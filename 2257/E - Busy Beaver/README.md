And now, in order to build up the company's reputation, it needs to construct the tallest building possible.</p><p>The company has an initial capital of $$$x$$$ carrots (a very valuable currency for beavers) and $$$n$$$ projects available for construction. A separate site has been allocated for each project, and nothing has been built there yet. A building project is represented by a sequence of contracts for constructing the next floor. To build the $$$j$$$-th floor of the $$$i$$$-th building, it is necessary to spend $$$a_{i, j}$$$ carrots; upon completing it, the company immediately receives $$$b_{i,j}$$$ carrots, which are added to the budget, and the company may use them to build higher floors of the same building or to work on other projects. Since the company is still young, not all contracts are necessarily profitable; in other words, it is possible that $$$a_{i,j}  \gt  b_{i,j}$$$.</p><p>The Beaver hired you to plan the company's course of action. You choose in which order to build which floors. Note that it is not necessary to complete projects, or even to start them at all. The main goal is — to build the tallest building possible.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. 10^9)$$$.</p><p>It is guaranteed that the sum of $$$m_i$$$ over all test cases does not exceed $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div
